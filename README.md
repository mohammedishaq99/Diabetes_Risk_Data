Diabetes Risk Data

Project Overview

This project contains a cleaned diabetes risk dataset and a Tableau dashboard for analyzing factors associated with diabetes.

Dataset

The dataset includes the following variables:

* Gender — Patient gender
* Age — Patient age
* Hypertension — Whether the patient has hypertension
* Heart Disease — Whether the patient has heart disease
* Smoking History — Patient smoking history
* BMI — Body Mass Index
* HbA1c Level — HbA1c blood test level
* Blood Glucose Level — Blood glucose measurement
* Diabetes — Diabetes outcome

Files

* Diabetes celaned (1).csv — Cleaned diabetes dataset
* Diabetes Risk Dashboard.twb — Tableau dashboard file
* README.md — Project documentation

Dashboard

The Tableau workbook can be opened using Tableau Desktop or Tableau Public.

Data Format

The cleaned dataset is stored as a CSV file using semicolons (;) as the field delimiter.
